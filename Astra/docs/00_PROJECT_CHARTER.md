# Project Charter

## Mission
Astra is a Personal AI Runtime that understands user intent, plans actions, executes them safely, and remembers long-term context.

## Success Criteria
- Natural voice interaction
- Persistent memory
- Reliable desktop automation
- Modular architecture
- Linux-first
- Extensible capability framework

## Non Goals
- Build a custom LLM
- Build custom STT/TTS
- Replace the operating system

## Product Values
1. Reliability over cleverness.
2. Deterministic planning when possible.
3. Memory before personality.
4. User control over automation.
