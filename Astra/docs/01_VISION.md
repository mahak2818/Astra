# Vision

Astra is not a chatbot.

Astra is a persistent AI operating layer between the user and the computer.

Pipeline:

User
→ Perception
→ Intent
→ Planner
→ Capabilities
→ Response

Long-term goals:
- Continue unfinished work automatically.
- Remember projects.
- Control the desktop.
- Search the web.
- Integrate cloud and local AI.
